# DOCX Documentation Structure

This folder contains finalized Word deliverables and their image assets.

## Structure

- `frontend/`
  - `DocMind_Architecture_Frontend_v1_1.docx` (current)
  - `images/` (frontend diagrams)
- `fullstack/`
  - `DocMind_Architecture_Fullstack_v1_1.docx` (current)
  - `DocMind_Updation_Traceability_v1_1.docx` (current)
  - `DocMind_Release_Checklist_v1_1.docx` (current)
  - `images/` (full stack diagrams)
- `backend/`
  - `DocMind_Architecture_Backend_v1_1.docx` (current)
  - `images/` (backend diagrams and assets)
- `reference/`
  - Source enterprise/reference Word files
- `archive/`
  - Version history snapshots (for example `archive/v1_0/`)

## Notes

- Keep only publish-ready artifacts in this folder.
- Generation scripts are maintained under `docs/scripts/doc_generators/`.
- Keep older versions only as explicit history snapshots under `docs/docx/archive/`; latest baseline is v1_1.
